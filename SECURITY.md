# Política de Segurança

Este repositório reúne documentos (Markdown e um logotipo), não software em execução. Um problema de segurança aqui é, provavelmente, um segredo vazado, uma exposição de dados pessoais ou um link que leva a algo inseguro.

## Como relatar um problema

Por favor, não abra uma issue pública nem um pull request para um problema de segurança.

1. Abra a aba **Security** deste repositório.
2. Escolha **Report a vulnerability**.
3. Descreva o que você encontrou e onde (arquivo e linha, se puder).

O relato fica visível apenas para os mantenedores. Este repositório não publica um endereço de e-mail para relatos de segurança.

## O que esperar

- Vamos ler o seu relato e responder pelo mesmo formulário privado.
- Vamos informar se aceitamos o relato como um problema e o que pretendemos fazer.
- Pedimos que você mantenha os detalhes em sigilo até a correção.

Este é um projeto pequeno. Não podemos prometer um prazo fixo de resposta.

## Versões com suporte

Apenas o conteúdo atual do branch `main` é mantido.
